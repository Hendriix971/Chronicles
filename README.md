# Chronicles V15.13 — Contrat de guilde compact

Base : Chronicles V15.12. Correctif d’interface **exclusivement dans la Messagerie**.

- Le document officiel beige conserve son identité visuelle, les six articles, les clauses contractuelles, les signatures et toutes les informations financières.
- Sur grand écran, les articles sont disposés en **deux colonnes lisibles** (I–III à gauche et IV–VI à droite), avec des marges et un en-tête resserrés. L’objectif est de limiter le défilement avant de pouvoir lire le contrat et utiliser les boutons.
- Sur une largeur plus faible, la présentation repasse en une colonne pour éviter des colonnes illisibles.
- Les actions (signature, refus, négociation) et le comportement de la simulation sont inchangés.
- Sauvegardes : préfixe `chronicles_v1513_world_` et base `chronicles_v1513_sauvegardes`. Copie depuis V15.12 et les autres éditions compatibles, sans modifier les originales. **Conservez un export JSON** de votre partie avant l’essai.

Extraire le ZIP, conserver la structure des fichiers et lancer `index.html` avec Brave / Chromium.
